# NewCo Financing Data Room — Reusable Outline

Version 1.0 | September 19, 2026

A basic outline for a U.S. startup raising a SAFE, convertible note, or priced equity round. Default: a Delaware C corporation, with optional founder holding-LLC records. It organizes what investors are funding, who owns it, obligations, and financing effects. It contains no company documents and is not an investor-readiness certification or a set of financing agreements.

## Start here

1. Copy this directory for the actual company.
2. Complete [room administration](00-index-and-diligence-tracker/README.md) and select the applicable financing checklist.
3. Assign owners in the [document index](00-index-and-diligence-tracker/document-index.md); upload/link evidence and record its version and date.
4. Mark genuinely absent/inapplicable items with explanations. Track unknowns and missing records separately.
5. Reconcile the evidence using [readiness checks](READINESS.md), then configure sharing using [access guidance](ACCESS.md).

## Folders

- 00 — Index and diligence tracker
- 01 — Investment overview
- 02 — Formation and governance
- 03 — Capitalization and equity
- 04 — Intellectual property and technology
- 05 — Team and service arrangements
- 06 — Financials and operating plan
- 07 — Customers and commercial agreements
- 08 — Tax, compliance and risk
- 09 — Current financing and closing: SAFE, convertible note, priced round and common closing

Each folder README describes required evidence categories. Not every company needs every item. Pre-revenue NewCos can have no customers or historical revenue; say so accurately. Regulated activities and particular investor requirements may expand the list.

## Founder model and existing assets

For a shared founder holding LLC, include both corporate and LLC records, actual ownership/vesting, signing authority and required financing approvals. Show corporate outstanding shares separately from a fully diluted view and indirect founder economics. Do not count an unallocated option pool as issued stock.

For a NewCo using an existing business’s assets, document ownership, assignments/licenses, consents and assumed obligations. New incorporation does not itself transfer assets. Label predecessor financials separately. Keep factual QSBS support and applicable election evidence in restricted diligence; do not promise eligibility based only on entity type.

## Naming and authoritative records

Use `YYYY-MM-DD_Document-name_Status.ext`, with statuses such as Draft or Executed. Preserve complete signed copies and associated amendments. Cross-link a single authoritative copy when multiple folders need it. Do not put private business records in a public website repository.

## Reference frameworks

- [YC SAFE forms and guidance](https://www.ycombinator.com/safe): SAFE variants and side letters; separate from debt-note documents.
- [NVCA model legal documents](https://nvca.org/model-legal-documents/): priced equity transaction-document categories.

This is a practical suggested outline, not a claim that every investor or law requires every listed item. Counsel determines the financing documents, approvals and filings for the actual transaction.

## Use and sharing

The Markdown (`.md`) files are plain text: edit them in a text editor or import/copy their contents into your preferred document tool. Upload the extracted folders to your chosen private storage platform. Access labels do not set permissions. See [LICENSE.md](LICENSE.md) and [DISCLAIMER.md](DISCLAIMER.md).
