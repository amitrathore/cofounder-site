# Formation and governance

Store or link the applicable records below. This template contains no company evidence. Default owner: room owner until assigned.

| ID | Record | Contents | Suggested access |
| --- | --- | --- | --- |
| 02-01 | Formation documents | Filed charter and amendments, bylaws, EIN confirmation. | Diligence |
| 02-02 | Corporate actions | Incorporator actions; board/officer appointments; board and stockholder minutes and consents. | Diligence |
| 02-03 | Status and registrations | Good-standing evidence and applicable state registrations. | Diligence |
| 02-04 | Entity and ownership diagram | Operating company, subsidiaries, founder holding vehicles and relevant beneficial ownership. | Diligence |
| 02-05 | Founder and governance agreements | Cofounder, stockholder, voting and other governance agreements. | Diligence |
| 02-06 | Rights and related-party schedule | Approval and board rights; related-party arrangements; required financing consents. | Diligence |

For a possible founder-governance starting point, see the [Cofounder Agreement v2 public review draft](https://cofounder.community/legal/awake-cofounder-agreement/v2/). Use of that template is optional, not a financing requirement.
