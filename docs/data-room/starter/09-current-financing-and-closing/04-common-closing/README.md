# Common closing records

- Closing checklist with responsible person, prerequisite and completion evidence.
- Executed agreements and amendments, with all signature pages.
- Funding confirmations reconciled to signed amounts; restrict bank information.
- Updated ownership/instrument records and applicable filing receipts.
- Post-closing obligations, responsible person and deadlines.

Maintain separate `drafts/`, `executed/`, and `superseded/` subfolders. Label draft status explicitly.
