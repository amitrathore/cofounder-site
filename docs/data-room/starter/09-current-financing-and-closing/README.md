# Current financing and closing

Use the checklist for the selected instrument, plus common closing records. Preserve prior financing instruments in the cap-table index; link to authoritative copies instead of maintaining inconsistent duplicates.

- [SAFE](01-safe/README.md)
- [Convertible note](02-convertible-note/README.md)
- [Priced round](03-priced-round/README.md)
- [Common closing](04-common-closing/README.md)

A standard YC SAFE is not a debt note and has no interest or maturity date. Use the actual instrument terms when modeling conversion. [YC forms and guidance](https://www.ycombinator.com/safe).

The priced-round categories reflect the [NVCA model-document suite](https://nvca.org/model-legal-documents/); counsel determines the transaction-specific package.

Keep wire instructions in a separately verified closing process, not in the generally shared data room. Never treat receipt of an emailed instruction change as verification.
