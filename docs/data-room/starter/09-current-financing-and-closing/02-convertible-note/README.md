# Convertible note

- Note and any purchase agreement, with proposed terms.
- Interest, maturity, conversion triggers, repayment and default terms.
- Security, guarantees or subordination documents, if applicable.
- Principal and accrued-interest schedule and conversion model.
- Required approvals, waivers and investor side letters.

Maintain separate `drafts/`, `executed/`, and `superseded/` subfolders. Label draft status explicitly.
